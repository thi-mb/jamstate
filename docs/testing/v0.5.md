# v0.5 Guitar: test plan

Play a guitar (or anything with a mic) into an audio interface and the band
follows, with no MIDI pickup; strummed chords and single notes show on the
fretboard; say a cue instead of pressing it
([roadmap](../roadmap.md#v05-guitar), [ADR-0023](../decisions/0023-audio-input.md),
[ADR-0024](../decisions/0024-chord-detection.md),
[ADR-0025](../decisions/0025-bleed-gating.md),
[ADR-0026](../decisions/0026-voice-cues.md)). This first iteration is tuned
on synthesised guitar, GuitarSet and synthesised speech
(2026-11-14); a fine-tuning pass follows real guitar jams. The automated
checks cover everything that doesn't need hands; the rows under
**Hands-on checks** are the playing checks.

Result legend: ✅ pass · ⚠️ works but needs tuning · ❌ broken · ⏭ skipped

## Hands-on checks

Runs on the Spark's main page: `ssh -fN jamstate`, then
http://localhost:8765. Guitar into the Scarlett Solo's instrument input
(input 2), headphones on the Scarlett unless the row says otherwise. Under
**You**, pick **Audio**, the Scarlett and channel 2, and run **Calibrate**
once.

| # | Test | How | What "good" looks like | Result | Notes |
|---|------|-----|------------------------|--------|-------|

| T2 | Single notes | Blues in A, fretboard on: play a slow blues line | Each note lights one spot on the neck, near where you're playing, green/yellow/red by fit | | |
| T3 | Chords | Night Shift, then Late Set: strum the changes | The chord shows within about a beat, in a shape you could be playing | | |
