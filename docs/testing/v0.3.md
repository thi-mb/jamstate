# v0.3 Listening: test plan

The leader hears more of your playing (song position, rhythm, harmony,
phrasing, dynamics), takes cues from the keyboard, can follow your tempo,
and gets a score from the eval set; a fretboard or piano shows the scale and
how your notes fit ([roadmap](../roadmap.md#v03-listening),
[eval scenarios](../eval/scenarios.md)). Claude runs everything that doesn't
need hands; the rows under **For Thiago** are the playing checks.

Result legend: ✅ pass · ⚠️ works but needs tuning · ❌ broken · ⏭ skipped

## For Thiago

Runs on the Spark's "next" channel:
`ssh -fN -L 8766:localhost:8766 jamstate`, then http://localhost:8766.
Bandleader on Jev unless the row says otherwise. Record every jam (it's on
by default) and download the three in T9.

| # | Test | How | What "good" looks like | Result | Notes |
|---|------|-----|------------------------|--------|-------|
| T1 | Call and response | Blues in A: play a 2-bar phrase, leave 2 bars, repeat for a couple of choruses | The band keeps going in the gaps, maybe answers with a fill; it doesn't drop out or swing up and down | | |
| T2 | Build into a chorus | Night Shift: start sparse in the verse and build up over its last 8 bars | The chorus arrives bigger, with a fill or crash into it | | |
| T3 | Sparse and stop | Any song: go sparse for a phrase, then stop for a phrase, then come back | Band lays back, then drops out, then comes back in | | |
| T4 | Follow my tempo | Late Set with **Follow my tempo** on: slow down a little over 8 bars; then turn it off and do it again | On: the band comes along, smoothly, and not past 5%. Off: the band holds | | |
| T5 | Cue keys | During a jam press 3 (build), 4 (take it down), 2 (break), 1 (next section), 5 (one more chorus), 6 (end song) | Each lands where it should (bar or phrase) and the leader doesn't undo it right away | | |
| T6 | Listening toggles | Night Shift: play outside the key for a phrase with Harmony on, then with it off | You can tell the difference, or tell us you can't | | |
| T7 | Fretboard | Each song, guitar then piano view, play along | The right scale and chord tones, the next chord fading in before the change, your notes coloured by fit | | |
| T8 | Nothing stutters | Over all of the above | No dropped bars or hiccups with the bigger summary | | |
| T9 | Three jams for the eval | One jam per song, a few minutes each, playing however you like; **Download** each | Three session files, sent to Claude to label as eval scenarios | | |
