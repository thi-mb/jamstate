# v0.2 Sound and lineup: test plan

The built-in band plays sampled instruments through a mix per genre, has
three more parts (guitar, pad, percussion), and each song says who plays
([roadmap](../roadmap.md#v02-sound-and-lineup),
[ADR-0018](../decisions/0018-lineups-and-sound.md)). Claude ran everything
that doesn't need ears; the rows marked **Thiago** are the listening and feel
checks, including the re-run of v0 test 10.

Result legend: ✅ pass · ⚠️ works but needs tuning · ❌ broken · ⏭ skipped

## For Thiago

The branch runs on the Spark next to the usual page (the "next" channel):
`ssh -fN -L 8766:localhost:8766 jamstate`, then http://localhost:8766. Use
built-in sound only (no MIDI out) for T1 to T4.

| # | Test | How | What "good" looks like | Result | Notes |
|---|------|-----|------------------------|--------|-------|
| T1 | Test 10 again: would you post it? | Pick any song, jam 30 s with the built-in sound, record it (QuickTime or the phone) | You'd post it. Note which part sounds weakest |  |  |
| T2 | Two lineups | Late Set on its band (brushes, upright, piano); then Blues in A on its band (kit, electric bass, organ, guitar) | Sounds like a jazz trio, then like a blues band |  |  |
| T3 | Switch while playing | During a jam, change the keys' instrument and turn the guitar off and on | No click, no dropped bar; the new sound comes in on the next notes |  |  |
| T4 | Genre changes the band | Same song, switch genre between funk, blues rock and jazz | Each default sounds like that genre (room, drums, keys) |  |  |
| T5 | The mix by genre | Listen for balance in each default: is any part buried or too loud? | Nothing buried; bass and drums sit together |  |  |
| T6 | MIDI out per part (optional) | MIDI out to Ableton, one track per channel 1–5, 10, 11 | Each part arrives on its own channel |  |  |

If a sound is weak, say which: any instrument can be re-rendered from a
better source without code changes ([samples.md](../samples.md#replacing-an-instrument)).
