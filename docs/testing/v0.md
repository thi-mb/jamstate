Run by Thiago on 2026-10-30: Mac (Chrome) through an SSH tunnel to the DGX Spark, Komplete Kontrol M32, Ableton over the IAC bus.

Setup: on the Mac, `ssh -fN jamstate`, then open http://localhost:8765 in Chrome.
To deploy new code first: `ssh spark 'cd ~/dev/jamstate && git pull && cd web && npm ci && npm run build'` then `ssh spark systemctl --user restart jamstate-app`.
