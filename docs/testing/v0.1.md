# v0.1 Groove: hands-on test plan

What v0.1 should sound like ([roadmap](../roadmap.md#v01-groove)): the band
plays like people, not a sequencer. It swings, breathes, counts you in and
ends songs properly, and the same chart in two genres sounds like two bands.
The instruments still sound like simple synths (better sounds are v0.2), so
judge the playing through Ableton where you can.

Setup: on the Mac, `ssh -fN jamstate`, then open http://localhost:8765 in Chrome.

Deploy first (on the Spark, from the Mac):

```bash
# before the PR is merged, check out the branch; after, just pull main
ssh spark 'cd ~/dev/jamstate && git fetch origin && git checkout claude/project-thread-5oe9e0 && git pull && cd web && npm ci && npm run build'
ssh spark systemctl --user restart jamstate-app
```

No systemd or sudo changes: saved sessions go to `~/.local/share/jamstate/sessions` on the Spark, created on first save.

For the "through Ableton" tests: MIDI out = IAC bus, untick **built-in sound**,
three MIDI tracks on channels 2 (bass), 3 (chords) and 10 (drums) as in the
[README](../../README.md#playing-the-band-through-a-daw). Use the same three
instruments for every genre, so the playing is what changes. The drum rack
needs ride (51), ride bell (53) and pedal hat (44) now, besides v0's pads.
